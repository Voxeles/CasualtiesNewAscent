### Casualties: Unknown - New Ascent Sequence

A mod that changes the ascent

### Installation:
1. Download .dll from [releases](https://github.com/Voxeles/CasualtiesNewAscent/releases)
2. Put the .dll file in your BepInEx/plugins folder
3. Optionally, download the save file as well and put it in "%userprofile%\AppData\LocalLow\Orsoniks\CasualtiesUnknown" if you want to start in WWMR with some gear
